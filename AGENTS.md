# Contexto del Proyecto: Aplicación de Lista de Tareas

## Visión General
El propósito de este proyecto es desarrollar una aplicación web local de **Lista de Tareas** (To-Do List). La herramienta está pensada para ejecutarse de forma ágil y autónoma directamente en el navegador web, permitiendo al usuario gestionar sus actividades de manera organizada, clara e intuitiva.

## Alcance y Tecnologías
El proyecto se desarrollará exclusivamente en el **frontend**, sin requerir infraestructura de servidor ni bases de datos remotas. Las tecnologías base establecidas son:

- **HTML**: Para la estructura semántica de la aplicación.
- **CSS**: Para personalización de estilos, detalles visuales y refinamiento de la interfaz.
- **JavaScript**: Para la lógica de negocio en cliente y la interactividad de la interfaz.
- **Bootstrap & Bootstrap Icons**: Para agilizar el diseño de la interfaz gráfica, componentes visuales responsivos e iconografía moderna.
- **Local Storage**: Para la persistencia local de la información del usuario en el navegador entre sesiones.

## Objetivo
Crear una herramienta práctica, atractiva visualmente y de fácil uso para la organización cotidiana, manteniendo una arquitectura limpia y autosuficiente orientada a la experiencia de usuario.
